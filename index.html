Core Philosophy

Three Foundational Pillars of Architecture

Every design decision in AgendOS is anchored by three uncompromising principles of engineering excellence.

I

Multimodal Intelligence

Adaptive Edge & Cloud Reasoning

  • Hybrid AI Routing: Dynamic dispatch between Android AICore, Chrome window.ai, and Gemini 2.5 Flash.
  • Semantic Hash Caching: SHA-256 filter intercepts repetitive queries to deliver sub-millisecond cached responses.
  • Hands-Free Accessibility: Continuous voice ingestion with deterministic verbal confirmation loops for driving and accessibility.
Gemini Nano PDF.js Web Workers SHA-256
II

Local-First Reliability

Zero-Latency Optimistic State

  • Optimistic UI: Instantaneous screen updates writing to UID-scoped local storage before network handshake.
  • Offline Sync Queues: @capacitor/network sensor holds pending mutations in resilient queue buckets.
  • Conflict Reconciliation: Timestamp-based comparison engine (updatedAt / createdAt) guarantees zero data loss.
IndexedDB @capacitor/network Atomic Sync
III

Zero-Trust Security

Cryptographic Defense-in-Depth

  • RS256 JWT Verification: Independent gateway validation using dynamic Google Public CA certificates.
  • Strict Data Isolation: Every record partitioned at client and backend tiers by Firebase uid.
  • Defense-in-Depth: 20-field whitelist sanitization, Helmet CSP, receipt replay hashing, and dual-tier rate limiting.
RS256 Helmet CSP Rate Limiting

Multimodal Engine

Continuous Multimodal Ingestion & Hands-Free Safety

Accepting continuous voice streams, multi-page flight PDFs, schedule camera photos, and calendar files—with instant semantic caching and hands-free verbal confirmation.

Slide 05

Continuous Inputs

Audio, Vision & Document Web Workers
  • Voice Streams: .webm, .wav, and live mic streams. Voice engine understands relative time expressions (e.g., "next Tuesday after lunch") natively.
  • Multi-Page PDF Parsing: PDF.js running inside dedicated Web Workers extracts calendar events from flight itineraries, meeting invites, and medical slips.
  • Canvas Image Compression: Client-side canvas downsampling compresses schedule photos prior to cloud transmission to optimize network bandwidth.
Slide 07

Semantic Hash Caching

Sub-Millisecond Cache Interceptor
  • SHA-256 Filter: Computes cryptographic hashes of incoming queries and multimodal inputs before sending them over the wire.
  • Zero Cloud Cost: Repeated prompts (e.g. "What is on my agenda tomorrow?") return instantly from memory.
  • Bypasses API Consumption: Drastically reduces latency and protects against cloud quota exhaustion.
Slide 08

Verbal Confirmation Loop

Deterministic Spoken Safeguard
  • Speech Synthesis Prompt: System speaks back: "Should I reschedule Team Sync to Thursday at 10 AM?"
  • Deterministic Confirmation: Requires explicit spoken "Yes" or "No" before executing local database writes.
  • Zero Accidental Loss: Designed specifically for driving safety and accessibility for visually impaired users.

Enterprise Security

Zero-Trust Architecture & Stack Defense-in-Depth

Enforcing an ironclad security posture: Cryptographic RS256 JWT validation, strict UID data isolation, and comprehensive protection against injection and replay attacks.

Slide 11

Zero-Trust Client Boundary

Cryptographic RS256 Backend JWT Verification
  • Google Public CA Validation: Express server validates algorithm, issuer, expiration, and dynamic certificates independently against Google's public key authority.
  • UID-Scoped Database Partitioning: Client storage and backend Firestore collections are strictly isolated by authenticated Firebase uid.
  • Zero Client Privilege: Client-provided tokens cannot escalate permissions or access neighboring tenancy slots under any condition.
